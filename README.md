# Swiss Pickle

Eine responsive Web-App für Pickleball-Turniere im Schweizer System.

## Funktionen

- Teams und Anzahl der Plätze verwalten
- Automatische Paarungen nach Punkten und Buchholz
- Freilos bei ungerader Teamzahl
- Ergebnisse für Sieg, Niederlage und Unentschieden
- Nächste Runde erst nach vollständigen Ergebnissen
- Aktuelle Tabelle
- Automatische lokale Speicherung im Browser
- JSON-Export und JSON-Import

## Start

```sh
npm install
npm run dev
```

## Produktion

```sh
npm run build
npm run preview
```
